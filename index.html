Project overview

One coherent real-time ride-control system

The ThemePark Ride Safety & Dispatch Controller simulates the control system for a theme park ride. Sensor data is generated, transferred through a queue, evaluated by a safety controller, and coordinated using FreeRTOS synchronization primitives.

The real-time pipeline runs on Core 1 while monitoring and observability run on Core 0. This separation keeps serial output and optional web monitoring from interfering with time-sensitive ride-control tasks.

Key capabilities

  • Queue-based sensor pipeline
  • Event-group synchronization
  • ISR-to-task direct notification
  • Binary semaphore latency comparison
  • Mutex-protected shared state
  • Heartbeat watchdog and fault injection
  • WCET and latency measurements
